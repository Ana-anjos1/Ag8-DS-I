# Pesquisa de Opinião - TudoWeb

Um trabalho simples de Python que simula uma pesquisa de opinião com 50 pessoas sobre o atendimento da TudoWeb.

## O que o programa faz

Faz 50 entrevistas. Pra cada pessoa pergunta:

- Nome
- Idade
- Opinião sobre o atendimento (1 - Excelente, 2 - Bom, 3 - Ruim)

No final, mostra quantas pessoas responderam **EXCELENTE** e quantas responderam **RUIM**.

## Como rodar

Precisa ter o Python instalado na máquina. Depois é só abrir o terminal na pasta do arquivo e rodar
