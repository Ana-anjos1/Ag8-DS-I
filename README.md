📊 Pesquisa de Opinião - TudoWeb

📌 Descrição

Este projeto foi desenvolvido em Python para realizar uma pesquisa de opinião sobre o atendimento ao cliente da empresa fictícia TudoWeb.

O programa coleta informações de 50 entrevistados, utilizando estruturas de repetição e decisão.

🎯 Objetivos

- Solicitar o nome do entrevistado;
- Solicitar a idade do entrevistado;
- Solicitar a opinião sobre o atendimento;
- Registrar as opções:
  - 1 - EXCELENTE
  - 2 - BOM
  - 3 - RUIM
- Contabilizar as respostas EXCELENTE;
- Contabilizar as respostas RUIM;
- Exibir os resultados ao final da pesquisa.

💻 Tecnologias utilizadas

- 🐍 Python
- 🔄 Estrutura de repetição "for"
- 🔀 Estruturas de decisão "if" e "elif"
- 🔢 Variáveis contadoras

🧠 Funcionamento

O programa solicita os dados de cada entrevistado e repete esse processo até completar 50 entrevistados.

Ao final, são exibidas na tela:

- Quantidade de respostas EXCELENTE;
- Quantidade de respostas RUIM.

🧪 Teste

Foi realizado um teste com 10 entrevistados para verificar o funcionamento do programa.

Exemplo de resultado:

Quantidade de respostas "EXCELENTE": 4
Quantidade de respostas "RUIM": 3

O resultado pode mudar de acordo com as respostas informadas durante a execução.
